Qor jangi - Render'ga joylash

1. Bu papkadagi fayllarni GitHub'da yangi repozitoriyga yuklang (server.js, package.json, render.yaml, public/index.html).
2. render.com > New > Web Service > shu repozitoriyni tanlang.
   Runtime: Node. Build: npm install. Start: npm start. Plan: Free.
3. Deploy tugagach, Render bergan manzilni (https://NOM.onrender.com) ikkala qurilmada oching.
   Sahifa ham, signal serveri ham shu manzilda ishlaydi, boshqa sozlash kerak emas.

Eslatma: bepul rejada server 15 daqiqa jim tursa uxlaydi. Birinchi ulanish 30-60 soniya olishi mumkin,
o'yin buni o'zi kutadi ("Server uyg'onmoqda...").
